# ISO 27001:2022 ISMS Implementation — Bank Al-Afaq Al-Raqmia

**A complete mock implementation of an Information Security Management System (ISMS) based on ISO/IEC 27001:2022 for a fictional Saudi digital bank.**

**تطبيق تجريبي كامل لنظام إدارة أمن المعلومات وفق معيار ISO/IEC 27001:2022 لبنك سعودي رقمي (خيالي).**

---

## 📌 About the Project

This repository contains a **full ISMS implementation project** aligned with **ISO/IEC 27001:2022**, developed as an academic final project. It demonstrates how a financial institution designs, documents, and prepares for certification of an Information Security Management System.

**Project Scope:**
- **Organization:** Bank Al-Afaq Al-Raqmia (بنك الآفاق الرقمية) — fictional Saudi digital bank
- **Industry:** Banking & Financial Services
- **Standard:** ISO/IEC 27001:2022
- **Deliverables:** 18 documents + 4 security operating procedures
- **Annex A Controls:** 93 assessed (72 implemented)
